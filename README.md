Концепция веб-плаката «Wings Melody»

Это интерактивная «музыкальная лаборатория», в которой пользователь выбирает себе наставника из трёх птиц: совы, попугая и дятла. Каждая птица задаёт уникальную цветовую палитру и атмосферу, сопровождая пользователя на всём пути создания музыки.

Путь построен как последовательность из пяти экранов.

Выбор наставника
знакомство с птицами, смена визуального стиля. Кнопка «Выбрать» запускает путешествие.
Музыкальный тетрис перетаскивание нот и инструментов в пустые клетки, сборка собственного звукового набора.
Звуковая студия интерактивный пульт с рычажками, кнопками, ползунками и пианино для экспериментов со звуком.
Игра на внимание
ловля виниловых пластинок среди падающих нот.
Проигрыватель
кульминация: выбранная пластинка переносится на диск, игла опускается, звучит трек.

Весь проект выполнен на HTML, CSS и JS с резиновой версткой, адаптивностью и единой логикой смены визуального стиля в зависимости от выбранной птицы.
